# Changelog

> Current release notes are published on the [GitHub Releases page](https://github.com/devs-infrastructure/traeflare/releases).

## 1.0.0 - 2026-10-13

- Launched Traeflare under its new home.
- Replaced the legacy custom base image with the official Python 3.14 Alpine image.
- Updated and pinned all Python dependencies.
- Added an independent multi-architecture GHCR build and vulnerability scan.
- Defaulted logging to stdout for container-native operation.
- Updated project ownership, image references, and documentation.
